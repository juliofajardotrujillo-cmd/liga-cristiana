CARPETA DE IMAGENES
====================

Aqui van los escudos de los equipos y el balon. Actualmente contiene
placeholders generados automaticamente (circulos de color con siglas)
para que la app se vea completa desde el primer momento.

Para poner tus imagenes reales, simplemente reemplaza cada archivo
por el tuyo MANTENIENDO EXACTAMENTE EL MISMO NOMBRE:

  escudo_sinai.png        -> escudo de Sinai
  3ra_bautista.png        -> escudo de 3ra Bautista
  el_cordero.png          -> escudo de El Corderito
  pedro.png               -> escudo de Pedro
  liga_evangelica.png     -> escudo de Liga Evangelica
  roca_fuerte.png         -> escudo de Roca Fuerte
  trionda_5_photoroom.png -> balon Trionda (el que se mueve en Inicio)

No hace falta tocar ningun archivo de codigo: el proyecto ya apunta
a estas rutas (/images/nombre.png) desde src/data/teams.js e
src/pages/Inicio.jsx.
